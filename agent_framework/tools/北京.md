## 三、每日详细行程

### 🚩 Day 1 — 中轴线经典（故宫线）

| 时间 | 安排 | 备注 |
|------|------|------|
| 上午 8:30 | **故宫博物院** | 门票 ¥60，需提前 7 天预约 |
| 中午 | 老北京炸酱面 / 豆汁焦圈 | 景山附近，尝鲜体验 |
| 下午 14:00 | **景山公园**（¥2） | 万春亭俯瞰故宫全景，绝佳机位 |
| 下午 15:30 | **南锣鼓巷 / 什刹海** | 胡同citywalk、后海骑行 |
| 晚上 18:30 | **前门大栅栏** | 老字号逛街 |
| 晚上 19:30 | **四季民福烤鸭** | 人均 ¥150 |

**⚠️ 重点提醒**：
- 故宫一定提前 7 天在"故宫博物院"小程序抢票，旺季很难约！
- 推荐路线：午门进 → 太和殿 → 乾清宫 → 御花园 → 神武门出

### 🚩 Day 2 — 长城雄关（体力日）

| 时间 | 安排 | 备注 |
|------|------|------|
| 上午 | **慕田峪长城** | 门票 ¥40，人少更野趣，适合年轻人 |
| 中午 | 长城脚下农家菜 | 补充体力 |
| 下午 | **明十三陵·定陵** | 门票 ¥60，地下宫殿 |
| 晚上 | **鸟巢 + 水立方**夜景 | 免费外观打卡 |
| 晚上 | **簋街** 麻小/小龙虾 | 夜市美食 |

**⚠️ 重点提醒**：
- 慕田峪比八达岭人少，更符合年轻人喜好；八达岭名气大但人多。
- 建议报一日游或坐旅游专线，单程 1.5–2 小时。

## 六、实用贴士

1. **预约**：故宫、国博等必须提前预约，旺季提前 7 天抢票。
2. **交通**：地铁为主，下载"亿通行"App 或支付宝扫码乘车。
3. **天气**：北京春秋最佳，夏天炎热注意防晒，冬天干燥。
4. **长城**：避开节假日人流高峰，早出发。
5. **美食必吃**：烤鸭、涮羊肉、炸酱面、卤煮、豆汁（尝鲜）、驴打滚。
