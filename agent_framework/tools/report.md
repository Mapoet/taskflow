- 受强降雨影响，**天津滨海机场部分航班可能取消或延误**
- **出行建议**：出发前务必通过航司官网/APP或机场官方渠道查询航班实时状态

### 🚄 铁路
- 受台风影响，北方部分南北向铁路线路可能晚点/停运，需关注 12306 实时信息

### 🚗 地面交通

- 注意防范城市内涝、低洼路段积水
