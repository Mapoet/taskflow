# 宝鸡旅游指南

> 宝鸡古称"陈仓"，是华夏始祖炎帝故里、周秦文明发祥地，素有"炎帝故里、青铜器之乡"的美誉。这里既有深厚的历史文化底蕴，又有壮美的秦岭自然风光，是一座值得慢游细品的城市。

---

## 二、必游景点 TOP 10

### 1. 法门寺文化景区（扶风县）
- 世界唯一的释迦牟尼佛指骨舍利供奉地
- 法门寺地宫出土的唐代文物震惊世界
- 合十舍利塔造型独特，气势恢宏
- **门票**：约120元
- **建议游玩**：半天至一天

### 2. 太白山国家森林公园（眉县）
- 秦岭主峰，海拔3767米
- "太白积雪六月天"是关中八景之一
- 高山杜鹃、第四纪冰川遗迹、大爷海高山湖泊
- **门票**：约100元（不含索道）
- **建议游玩**：1–2天

### 3. 中国青铜器博物院（宝鸡市区）
- 国内最大的青铜器专题博物馆
- 镇馆之宝——"何尊"，铭文首现"中国"一词
- 馆藏文物1.2万余件（组）
- **门票**：免费（需预约）
- **建议游玩**：2–3小时

### 4. 周原遗址（岐山县）
- 西周王朝发祥地，中国考古学重镇
- 出土青铜器、甲骨文等珍贵文物
- 周文化研学旅行的重要目的地
- **门票**：免费或低价
- **建议游玩**：半天

### 5. 嘉陵江源头景区（凤县）
- 嘉陵江发源地，生态环境优越
- 高山草甸、原始森林、瀑布溪流
- 夏季避暑胜地
- **门票**：约60元
- **建议游玩**：半天至一天

### 6. 凤翔东湖
- 北宋大文豪苏轼任凤翔府签判时所建
- 与杭州西湖"姊妹湖"之称
- 湖光山色，亭台楼阁错落有致
- **门票**：免费
- **建议游玩**：2小时

### 7. 关山草原（陇县）
- 西北内陆难得一见的高山草原
- 骑马、滑草、露营等户外项目丰富
- 平均海拔2200米，夏季凉爽宜人
- **门票**：约60元
- **建议游玩**：1–2天

### 8. 石鼓山（宝鸡市区）
- 出土石鼓十面，为中国书法史上重要文物
- 石鼓阁可俯瞰宝鸡市区全景
- 中华石鼓园文化底蕴深厚
- **门票**：免费
- **建议游玩**：2–3小时

### 9. 大唐秦王陵（凤翔区）
- 唐朝开国皇帝李渊之父李虎的陵墓
- 规模宏大，出土文物丰富
- 历史文化研究价值极高
- **建议游玩**：2小时

### 10. 宝鸡天台山
- 佛教圣地，千年古刹林立
- 秦岭北麓自然风光秀丽
- 登山徒步的好去处
- **建议游玩**：半天

## 三、特色美食

### 必尝小吃
| 美食 | 特色 |
|------|------|
| **岐山臊子面** | 酸辣鲜香，面条薄筋光，臊子鲜香，汤酸辣开胃，是宝鸡最具代表性的名吃 |
| **擀面皮** | 筋道爽滑，配上油泼辣子，酸辣过瘾 |
| **豆花泡馍** | 地方特色早餐，豆花嫩滑，馍片香脆 |
| **凤翔豆花** | 细腻嫩滑，配以秘制调料 |
| **陇县核桃馍** | 皮脆馅香，核桃味浓郁 |

### 特色宴席
- **西府十三花**：宝鸡传统宴席，菜品讲究
- **岐山臊子面宴**：多种臊子面搭配，体验最地道的味道
- **麟游血条面**：地方特色面食

## 四、行程推荐

### 一日游（市区精华线）
- 上午：中国青铜器博物院 → 石鼓山
- 下午：金台观 → 陈仓老街
- 晚上：渭河公园散步

### 两日游（文化深度线）
- **Day 1**：中国青铜器博物院 → 石鼓山 → 凤翔东湖
- **Day 2**：法门寺文化景区 → 周原遗址

### 三日游（经典全景线）
- **Day 1**：中国青铜器博物院 → 石鼓山 → 陈仓老街
- **Day 2**：法门寺文化景区 → 凤翔东湖
- **Day 3**：太白山国家森林公园

## 五、交通指南

### 外部交通
- **高铁**：宝鸡南站，西安出发约1小时到达
- **普速火车**：宝鸡站，位于市区，交通便利
- **飞机**：咸阳国际机场（西安），转乘高铁或大巴约1.5–2小时

### 市内交通
- 公交系统完善，覆盖主要景点
- 出租车/网约车方便，起步价低
- 前往法门寺、太白山等郊区景点可乘旅游专线

---

## 六、实用贴士

1. **门票预约**：青铜器博物院等热门免费景点建议提前在官方平台预约
2. **登山准备**：太白山海拔较高，需准备保暖衣物，注意高原反应
3. **美食推荐**：岐山臊子面一定要在岐山本地品尝最正宗
4. **购物**：宝鸡特产有西凤酒、凤翔泥塑、陇县核桃等
5. **天气**：夏季多雨，秋季凉爽，出行前关注天气预报

## 七、周边联动

宝鸡地处黄金旅游带上，可联动游览：
- **东线**：西安（兵马俑、大雁塔）→ 咸阳 → 宝鸡
- **南线**：汉中（油菜花海）→ 宝鸡
- **西线**：天水（麦积山石窟）→ 宝鸡
