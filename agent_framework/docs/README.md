# Agent Framework 文档

本目录包含 Agent Framework 的完整文档。

## 目录结构

- **api/**：API 参考文档（使用 Doxygen 生成）
- **guides/**：使用指南和教程
- **architecture/**：架构设计和设计文档

## 主要文档

- 设计文档：`../readme/guide_agent.md`（在父目录的 readme 文件夹中）
- Taskflow workflow 文档：`../../workflow/README.md`

## 生成 API 文档

使用 Doxygen 生成 API 文档：

```bash
doxygen Doxyfile
```

生成的文档将在 `api/html/` 目录中。
